## 🚀 Projects

### ♟️ Chess Player

**Python · TensorFlow · Keras · NumPy · python-chess**

A neural-network chess opponent that learns a **value function** over board positions. The project uses one-hot board encoding, neural-network position evaluation, value-based move selection, depth-2 material search, and Monte Carlo reinforcement learning with discounted game returns. I'm also experimenting with connecting the model to a **servo-driven robotic arm**.

### 🔎 Younifind

**Next.js · TypeScript · PostgreSQL · OpenAI Embeddings**

A full-stack opportunity discovery platform with **REST APIs, authentication, RBAC, PostgreSQL, and semantic vector search**. Uses OpenAI embeddings to represent and retrieve similar opportunities based on their underlying content.

### 🤖 Beaver Breach

**Python · Flask · pandas · Firebase · Gemini API · TailwindCSS**

A data-driven web application for analyzing tariff-related data. Includes **CSV ingestion, data processing, backend APIs, automated analysis, interactive visualizations, and an AI-powered chatbot** using the Gemini API.

### 🩺 Diabetes Predictor

**Python · TensorFlow · Keras · scikit-learn**

A machine learning project comparing approaches for diabetes prediction. Includes **data preprocessing, logistic regression, neural networks, model training, evaluation, and visualization**.

### 📈 Stock Market Analysis

**Python · Apache Kafka · AWS EC2 · S3 · Glue · Athena**

A real-time data pipeline for streaming and analyzing stock market data. Uses **Kafka producers and consumers**, AWS EC2 for the streaming infrastructure, S3 for storage, and Glue/Athena for schema discovery and SQL-based analytics.

### 🏫 School Club Manager

**Python · Flask · SQLite · SQLAlchemy · PostgreSQL · Jinja**

A full-stack web application for managing school clubs and applications. Includes a **relational database model, SQLAlchemy ORM, role-based access control, server-rendered views, and database-backed workflows**.
